# Discord-Bot-Privacy-Policy
# Privacy Policy

Last Updated: June 2026

# Overview

This Privacy Policy outlines how the Barbie Discord Bot ("Bot") processes information during its operation in Discord channels.

By using the Bot, you accept the terms of this policy.

# Information we collect

During usage, the Bot will collect the following information:

* Discord User IDs
* Discord Server (Guild) IDs
* Discord Channel IDs
* Discord Role IDs
* Voice and Stage Channel usage information
* Event participation data and progress information
* Settings configured by server moderators

We do not collect passwords, payment details, or any personal sensitive information from the Bot.

# Usage of information

Collected information is processed strictly for providing our service, which includes:

* Tracking of voice and stage channel usage
* Calculation of event progress and achievement levels
* Rewarding and demoting role points
* Handling voice challenges and scheduled events
* Statistics generation (leaderboards, event data, and streaks)
* Optional notification events and award messages sent

# Message Content

The Bot does not read, process, or store content of messages.

# Presence Information

User presence information (online/offline/idle statuses) is not tracked or stored.

# Data sharing

Your data is not sold, leased, or transferred to any other party under any circumstances.

# Contact

If you have questions regarding this Privacy Policy or your data, please contact the developer through Discord.
